# 🌸 Thiệp Chúc Mừng 20/10 - Lớp 10A11

Một trang web thiệp chúc mừng ngày Phụ nữ Việt Nam 20/10 nhỏ nhắn, ngọt ngào dành tặng cho các bạn nữ lớp 10A11.

## 🚀 Xem Trực Tuyến (Live Demo)
Trang web được xuất bản miễn phí qua **GitHub Pages**.

## 🎨 Tính Năng & Thiết Kế
- **Bố cục Khung hoa (Floral Frame)** dịu dàng chuẩn thẩm mỹ tuổi học trò.
- Hiệu ứng hoa & trái tim rơi tự động sinh động.
- Nút tương tác mở hộp thư bí mật bất ngờ.
- Tương thích tốt trên cả điện thoại di động và máy tính.

## 🛠️ Công Nghệ Sử Dụng
- HTML5
- CSS3 (Flexbox, CSS Animations, Backdrop Filter)
- JavaScript (DOM manipulation)
